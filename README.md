# AI Chatbot with RAG and Memory
# CHAT-AI-CHAT-RAG

A **retrieval-augmented generation (RAG) chat application** that combines learning tools, a production-ready chatbot, a personal assistant, and a demo environment. Built to run **locally** with [Ollama](https://ollama.ai/) and [Mistral](https://mistral.ai/), this project supports **multi-document upload** for context-aware conversations.

---

## ✨ Features

- 🔍 **Retrieval-Augmented Generation (RAG)**: Use your own documents for context-aware answers.
- 📂 **Multi-document upload**: Drag and drop or upload multiple files.
- 🤖 **LLM Support**: Works with **Ollama** and **Mistral** models.
- 💻 **Full-stack setup**: React + Vite + Material-UI frontend, Node.js + Express backend, SQLite database.
- 🛠️ **Modes of use**:  
  - Learning tool  
  - Production-ready chatbot  
  - Personal assistant  
  - Demo project
- 🌍 **Localhost only**: No cloud dependency, your data stays local.
- 📝 **Lightweight DB**: SQLite for simplicity and portability.
